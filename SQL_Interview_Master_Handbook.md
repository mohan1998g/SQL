# Pattern Recognition Matrix

| Requirement | Pattern |
|-------------|----------|
| Summary Metrics | Aggregation |
| Filter Rows | Filtering |
| Multi-table Data | Join |
| Compare Same Table | Self Join |
| Above/Below Average | Subquery |
| Stepwise Logic | CTE |
| Ranking | Ranking |
| Running Values | Running Totals |
| Trend Calculation | Moving Average |
| Top K | Top-N |
| Consecutive Records | Gaps & Islands |
| Previous/Next Row | Window Functions |
| Hierarchy | Recursive CTE |
| User Activity Groups | Sessionization |
| Remove Duplicates | Deduplication |

# Final Notes
Most SQL interview questions can be categorized into these patterns. Pattern recognition is more valuable than memorizing individual queries.
